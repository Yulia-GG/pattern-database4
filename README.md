# Домашнее задание к занятию "Репликация и масштабирование. Часть 2" - Юлия Гриб

### Задание 1.

Опишите основные преимущества использования масштабирования методами:

1. Активный master-сервер и пассивный репликационный slave-сервер;
2. master-сервер и несколько slave-серверов;

**Активный master-сервер и пассивный репликационный slave-сервер** - это горизонтальное масштабирование, вид - репликация.

**Преимущества:**
- повышение производительности чтения: операции чтения можно выполнять на slave, разгружая master;
- хорошо для систем с преобладанием операций чтения над записью;
- повышение отказоустойчивости: если что-то случается с мастером, мы из реплики делаем основной сервер, при условии, что данные там не уничтожились;
- отсутствие конфликтов, так как источник записи только один;
- чем меньше slave-серверов, тем дешевле наш кластер;
- хорошо делать резервную копию.

**Мaster-сервер и несколько slave-серверов** - это горизонтальное масштабирование, вид - репликация.

**Преимущества:**
- масштабируемость чтения: распределение операций чтения между несколькими slave-серверами;
- можно распределять задачи по slave-серверам;
- повышенная отказоустойчивость: наличие нескольких реплик увеличивает надёжность и доступность данных;
- хорошо для систем с преобладанием операций чтения над записью, для тяжелых запросов;
- отсутствие конфликтов, так как источник записи по-прежнему один;
- хорошо делать резервную копию.

Примечание: При методе мaster-сервер и несколько slave-серверов при синхронном виде возможен недостаток: чем больше нагрузка, тем ниже быстродействие.
